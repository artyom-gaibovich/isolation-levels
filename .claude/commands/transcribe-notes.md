Ты эксперт в области баз данных, SQL, PostgreSQL, транзакций и уровней изоляции.

Тебе передан ID транскрипции: **$ARGUMENTS**

## Шаг 1 — Получи данные из БД

Выполни команду:

```bash
node scripts/db-get.js $ARGUMENTS
```

Из результата извлеки:
- `fileName` — имя файла для конспекта
- `transcriptionText` — текст транскрипции, на основе которого нужно создать конспект

## Шаг 2 — Создай конспект

На основе `transcriptionText` напиши подробный конспект в формате Markdown.

Правила составления конспекта:
- **Строго ориентируйся на материал из транскрипции** — не добавляй то, о чём не говорилось.
- Сохраняй все важные детали, примеры, цифры и формулировки из оригинала.
- Структурируй по темам/разделам с заголовками `##` и `###`.
- Используй маркированные списки для перечислений, кодовые блоки для SQL/Go/команд.
- Выдели ключевые термины **жирным**.
- Если в тексте есть примеры — включи их в конспект.
- Язык конспекта — тот же, что и в транскрипции (обычно русский).

## Шаг 3 — Сохрани файл

Сохрани конспект в файл: `notes/<fileName>.md`

Если директория `notes/` не существует — создай её.
