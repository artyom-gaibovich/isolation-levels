# Транзакция (Transaction)

## Что такое транзакция?

**Транзакция** — это *single unit of work*, то есть набор совокупных операций, которые рассматриваются как **одна атомарная единица**.

- Либо **все** операции выполняются вместе
- Либо **ни одна** из них не выполняется

## Жизненный цикл транзакции

### Успешное завершение — `COMMIT`

Если все операции выполнены корректно и база данных подтверждает, что все изменения валидны (соблюдены все ограничения: `UNIQUE`, `FOREIGN KEY`, `PRIMARY KEY`, диапазоны значений и прочее), то выполняется команда **`COMMIT`**.

- Все изменения **сохраняются** в базу данных
- Сохранение постоянное (связано со свойством **Durability** из ACID)
- Данные всегда можно будет прочитать обратно

### Откат транзакции — `ROLLBACK`

Если возникла какая-либо проблема:
- ошибка в логике программы
- нарушение ограничений базы данных

...то либо база данных сама, либо явно выполняется команда **`ROLLBACK`**.

- Откатываются **абсолютно все** изменения, произведённые в рамках транзакции — и "хорошие", и "плохие"
- Данные возвращаются в то состояние, которое было в самом **начале** транзакции (`beginning`)

## Наглядная схема

```
[Начало транзакции]
        |
   [Изменения данных]  ← данные меняют состояние
        |
   ┌────┴────┐
   │         │
[Всё ок?]  [Ошибка?]
   │         │
COMMIT    ROLLBACK
   │         │
[Данные   [Данные возвращаются
сохранены] в начальное состояние]
```

- **Синий прямоугольник** — транзакция
- **Маленькие квадратики** — данные, с которыми работает транзакция
- **Зелёный цвет** — данные были изменены в рамках транзакции (изменения ещё не зафиксированы)
